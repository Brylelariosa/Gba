# Duskhaven

A Minecraft-style isometric survival game for the Game Boy Advance.
Mine, craft, build, smelt, survive the night and light the Ember Beacon.

## Build

Drop the `src/` folder into your repo next to your existing `Makefile` and
GitHub workflow (both stay unchanged) and push. The workflow uploads the `.gba`
your Makefile builds - its `TARGET` decides the file name, so set `TARGET` to
`Duskhaven` there if you want the ROM file renamed too. No assets or extra
tools are needed: every texture, sprite and icon is generated by code at
start-up.

The game's name lives in one place: `GAME_NAME` in `src/config.h` (title screen
and goal messages).

If CI complains about `gbafix` or `-lgba`, add this step before "Build ROM":

    - name: Install GBA libraries
      run: dkp-pacman -S --noconfirm gba-dev

## Controls

| Button       | Action                                           |
|--------------|--------------------------------------------------|
| D-Pad        | Walk (tap = turn, hold = walk). Up = up-right    |
| A            | Mine / attack the block or mob in front (hold)   |
| B            | Place the selected block / eat food. Tap = 1 block, hold = a 2-high wall |
| L / R        | Previous / next hotbar slot                      |
| SELECT       | Inventory, crafting and goals                    |
| START        | Pause, save, how to play                         |

Hills and ledges that came with the world are climbed automatically. A block
you placed yourself is not: keep pushing into it for a moment to climb on top.
A wall two blocks high can not be climbed at all, so tap B (one block) or hold B
(a 2-high wall) to build walls, and leave a gap or place a door for the entrance.
Tapping B again keeps stacking, up to four high.

Facing the ground in front of you and holding A digs down. Blocks you place on
water replace the water surface, so you can build bridges (hold B and walk).

Doors: 4 planks at a crafting table. A door is two blocks tall, goes into a gap
in front of you, and you walk straight through it. Zombies and pigs can not, so
a house with 2-high walls and a door is safe at night. Mine a door (A) to pick
it back up.

## Progression

Chop a tree -> planks -> crafting table -> wood pickaxe -> cobblestone ->
stone pickaxe + furnace -> coal and iron ore -> iron ingots (furnace) ->
iron pickaxe -> diamond and gold -> glass (sand + coal) -> Ember Beacon
(3 diamond, 2 gold ingot, 1 glass). Place the beacon to win.

Tool tiers matter: stone and coal need a wood pickaxe, iron ore needs stone,
gold and diamond need iron. Zombies spawn at night, pigs drop pork (cook it in
a furnace). The game saves to the cartridge battery (SRAM) from the pause menu.

## Code layout (all in `src/`)

| Module                    | Job                                                  |
|---------------------------|------------------------------------------------------|
| `hw`, `sfx`               | Registers, DMA, input, sound (the only hardware code) |
| `world`, `move`           | Voxel world, terrain/caves/ores/trees, walking rules |
| `render`, `texgen`        | Isometric painter's-algorithm renderer, procedural textures |
| `palette`, `gfx`, `icons`, `sprites` | Day/night palette, 2D drawing + font, icons, OAM |
| `blocks`, `items`, `inventory`, `craft` | Data tables and inventory/crafting logic |
| `player`, `mobs`          | Player actions and zombie/pig AI                      |
| `ui`, `game`, `save`      | HUD and menus, state machine and goals, SRAM saves    |
| `config.h`                | Game name and tunables (walk speed, day length, building/climbing feel, ...) |

## Host tests (optional)

`host/` builds the real game code against fake GBA memory with
AddressSanitizer: `cd host && ./build_tests.sh && ./game_test` (gameplay),
`./build.sh && ./host_test out && python3 render.py out` (screenshots as PNG).
